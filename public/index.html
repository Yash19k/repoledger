Read-only, and it never sees your code

Every permission is read-only, and RepoLedger never asks for access to repository contents.

Can read

  • Traffic for the repositories you pick: views, clones, referring sites, popular pages
  • Star, commit, contributor, issue and pull-request counts
  • Repository settings, read-only. GitHub only shares traffic with apps that have this permission. RepoLedger uses it for traffic and nothing else.

Can't

  • Read your code or files. It never asks for that permission.
  • Change anything. Every permission is read-only.
  • See repositories you didn't select
  • See your password or email. The sign-in token is used once to learn your username, then revoked.

Questions

Who can see my traffic?

Only you, when signed in. Public lookups of your username never include traffic.

How far back does my history go?

GitHub keeps the last 14 days of traffic, so your history starts there on the day you sign in, and grows from then on. Stars are rebuilt back to the repository's first star.

How do I stop it?

Use Delete my data in the account menu, which uninstalls the app and deletes your stats immediately. Or uninstall RepoLedger from your GitHub settings; your data is deleted on the next collection run.

What is stored?

Your GitHub username and avatar, and the daily counts listed above. Nothing else.
